# Linux System Manager 🐧

A beginner-friendly Python project that displays Linux system information using Python.

## Features

- Displays current username
- Shows operating system information
- Displays Linux kernel version
- Detects system architecture
- Shows current working directory
- Displays current date and time
- Shows disk usage (total, used, and free space)

## Requirements

- Linux or Ubuntu WSL 2
- Python 3

## Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Go to the project directory:

```bash
cd system-manager
```

## Run the Project

```bash
python3 system-info.py
```
